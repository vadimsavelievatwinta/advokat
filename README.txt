Сайт адвоката Ольги Левадной: 3 варианта оформления в одном сайте.

Откройте index.html в браузере. Справа внизу кнопки «Исходный», «Светлый», «Зелёный». Выбор сохраняется в localStorage браузера.

Все 3 дизайна используют один HTML и одни разделы. Меняется цветовая палитра, фоны, акцентные кнопки.

Фотографии подключаются с images.unsplash.com и требуют интернета. Демонстрационное фото НЕ является реальной фотографией адвоката.

Перед публикацией заполните контакты, реальные отзывы и дела, политику конфиденциальности, подключите защищённую отправку формы.
